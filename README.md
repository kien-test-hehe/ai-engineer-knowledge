## Cách thêm nội dung sau này

1. Vào đúng topic folder trong `knowledge/`; giữ ID gốc để không mất liên kết.
2. Thêm kiến thức đã kiểm chứng vào `README.md` hoặc file Markdown riêng cùng thư mục; chưa duyệt thì tạo branch/PR.
3. Đặt notebook `.ipynb` tại `notebooks/`, hoặc lưu link Google Colab/Kaggle/nbviewer vào `notebooks/README.md`.
4. Ghi nhận kết quả kiểm tra L2/L3 riêng, không tự nhận hoàn thành chỉ vì đã đọc.
