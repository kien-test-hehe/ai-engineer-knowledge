# Learning progress / Review

Các topic đều bắt đầu với `mastery: unassessed`; chưa có bài kiểm tra, **không** tự đánh dấu L0.

- Trong topic README: `mastery`, `last_assessed`, `next_review`.
- `assessments.jsonl`: mỗi dòng tương lai là một JSON object ghi kết quả kiểm tra (roadmap_id, date, level, evidence, reviewer).
- `review-queue.csv`: danh sách các mục cần ôn, chỉ được điền sau khi có lịch đánh giá.

Đây là tracker, chưa chứa kết quả học tập thực tế.
