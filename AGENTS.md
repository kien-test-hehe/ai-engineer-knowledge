# AI Agent Working Rules

This repository is a learning knowledge base for the user's **AI ENGINEER ROADMAP 2026**.

- The roadmap source is `curriculum/ROADMAP_SOURCE.md`. Preserve the 10-part / 37-module / 219-subtopic hierarchy.
- The user is targeting **L2 comprehension** to **L3 independent application** for each topic. Do not conflate these with roadmap stage numbers.
- Never fabricate learning progress, references, test results, notebook outputs, or mastery ratings.
- Don't write learning notes automatically merely because a conversation happened.
- For knowledge changes, use a branch and Pull Request; obtain the user's review before merging.
- A scaffold README or syllabus checklist is **not** approved knowledge content.
- Prefer notebooks for runnable learning. Keep cells human-readable and commit actual saved outputs when safe and reasonable.
- Internal notebook paths are relative under each topic's `notebooks/`; external links belong in its notebook registry.
- Preserve citation/source provenance; distinguish observed measurements from interpretations and hypotheses.
- Read index → module/topic → relevant files. Do not load the whole repository into a model context unnecessarily.
- Topics initially have `mastery: unassessed`. Update only with explicit evidence from assessment.
- Avoid direct pushes to main for content changes unless the user explicitly instructs otherwise.
