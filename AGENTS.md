## Behavioral rules

- Teach **big-picture architecture → purpose → necessary math → implement → debug → evaluate → revisit**. Avoid endless calculation drills when skills can be demonstrated in an LLM implementation. Do not skip foundational reasoning.
- Keep Core/Working/Awareness/Advanced **target depth** separate from L2/L3 **observed mastery** and from V2 Phase 0–12 numbers.
- A historical Tensor Fundamentals L2 result of 90% concerns **that subscope only**; no full Linear Algebra or L3 completion is implied.
- No fabricated progress, scores, citations, measurements, benchmarks, notebook outputs, project implementations or model metrics.
- Read only relevant index/topic/files; do not load the entire repository unnecessarily.
- Don't automatically generate approved knowledge notes merely because a conversation took place.
- A scaffold syllabus or placeholder is not approved knowledge.
- Use notebooks for runnable learning, split into coherent cells; save real safe outputs when reasonable, record versions, seeds, datasets and benchmark hardware.
- Follow existing topic notebook registries. Do not commit private/secrets/weights/large datasets.
- Keep original file paths stable; new V2 path documents overlay old source structure instead of destructively replacing it.
- **Branch + Pull Request, human review before merge** for curriculum and knowledge changes. Do not push directly to main without explicit user request.
